# PLC 智能工程助手｜工程模板使用说明

模板用于从已经核实的参考工程创建新的评估副本。选择前应明确对应的设备型号与使用环境，创建时还会复核实际控制器；不符合条件时保留结果供核查，不自动替换控制器。

## 评估用户如何使用

先请助手列出当前可用模板及其对应条件：

> 列出本次环境中已准备的工程模板，说明对应设备和可用状态，先不要创建工程。

只有已经准备完成并通过核对的模板才可用于创建。确定目标模板、用途及新的副本位置后，再明确提出创建任务，并检查创建与控制器复核结果。

安装包只附带模板目录说明和登记资料，不含厂商参考工程。初次部署尚未准备模板时，没有可用模板是正常情况，不影响其他已具备条件的读取评估。

## 部署负责人需要确认

准备有权限使用的参考工程副本，核实其实际设备、软件环境及控制器身份，按维护流程完成登记。不能只凭文件名或型号标签猜测对应关系，也不能照抄开发环境的示例身份。

设备描述版本与控制器固件版本需要分别核实。缺少设备组件、型号不符或身份无法确认时，先解决准备问题，再开展模板创建。
