# Internal integration contract (v1)

Package: src/inoproshop_mcp. Public Core.call(tool_name, arguments) returns JSON dict; exceptions are DomainError(code,message,details). Server maps them to MCP tool errors.

2026-10-20 additive contract: 26 tools. `replace_st_sections` extends preview/apply to an existing ST POU declaration and/or implementation while preserving POU kind/name. Omission preserves a section, explicit empty implementation clears it, null is invalid. Native device snapshot rows now include `device_identity` (read/unavailable, type/id/version, evidence). `ino_list_project_templates` reads the explicit local catalog; `ino_create_project` binds catalog and file hashes, opens one new copy, verifies the unique native root controller and retains template provenance across rediscovery. Failed/unknown controller verification blocks writes. A rediscovered previously verified copy needs fresh controller verification before writing; an unresolved origin remains blocked. `context_search_text` reads immutable available text without graph/host calls and never claims semantic references. Existing graph requirements for modification preview, compile and recovery contracts remain unchanged.

State root default E:/AI-PLC/work/mcp_p0/state; allowed writable project root E:/AI-PLC/work/mcp_p0/projects. Token file state/token (do not log). Hosts register state/hosts/<host_instance_id>.json with host_id, host_instance_id, pid, pipe_name, heartbeat_at, project_path, binding_id, version. heartbeat_at uses Unix seconds. Pipe protocol uint32 LE length + UTF-8 JSON, max 16 MiB. Request {command_id,token,command,params}; response {ok,result} or {ok:false,error:{code,message,details}}. Service handles one command at a time per host. Every live command carries expected_binding_id; writes also carry expected_snapshot_hash or expected_node_hash. Result unknown must not retry a write.

Commands: capabilities, snapshot, compile, replace_text, import_st, delete_object, save_copy, open_project, shutdown (test-owned hosts only). snapshot returns ai_package.capture_project format nodes/relations/tasks plus binding_id, project_path, active_application_id, dirty, version. All node IDs are original GUIDs. normalize happens in Core. replace_text receives object_id, declaration, implementation, expected_node_hash; shared node hash is SHA256 of canonical JSON [declaration,implementation] (ensure_ascii=true, separators=(',',':')). import_st receives name,declaration,implementation,application_id. delete_object receives object_id and expected_node_hash. save_copy receives destination, expected_snapshot_hash; returns path and whether binding changed. open_project receives source,destination; never closes a dirty project; opening failure must preserve old project or explicitly report recovery. Native bridge limits all changes to allowed project root.

Root owns common.py, store.py, core.py, changes.py and core tests. Bridge agent owns adapters/inoproshop/bridge, transport.py, scripts/native*. Index agent owns index.py,cgc_backend.py and index tests. Server agent owns server.py,pyproject.toml,CLI/deploy scripts,OMP config examples,fixtures/evaluation,server tests. Agents coordinate before changing files outside their ownership.

Index API: PLCIndex(root:Path, backend=None); build(snapshot)->dict with index_revision,graph; search(snapshot,query,limit=50,offset=0,index_revision=None)->dict; references(snapshot,symbol_id,relation=None,index_revision=None)->dict; impact(snapshot,object_id,max_depth=3,index_revision=None)->dict. Snapshot includes project_id,snapshot_id,nodes,relations,tasks,hash. Graph JSON persists per revision. Distinguish deterministic local IR tests from real CGC/Neo4j integration evidence. Core imports index lazily.

Transport API: discover_hosts(state_dir)->list; PipeClient(host_record,token,timeout=120).call(command,params)->dict result, raises DomainError on known rejection and OPERATION_OUTCOME_UNKNOWN on write timeout. Core accepts injected transport_factory(host_record,token) for meaningful deterministic failure tests.
