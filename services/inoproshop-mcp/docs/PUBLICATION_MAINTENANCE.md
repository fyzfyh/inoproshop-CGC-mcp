# 隐私与发布范围

本仓库从 2026-10-20 已验收离线包的产品源码白名单建立，不从开发工作区整体执行上传。

- 提交服务、桥接、必要配套模块、合成测试与固定依赖、配置样例和说明。
- 排除工作目录、开发者数据库、token、凭据、模型配置与账号、原生验收门槛文件、IDE 工程、自动保存、缓存和个人规划记录。
- 运行环境及完整离线安装包在 GitHub Release 中交付，不作为 Git 历史中的大文件提交。离线 ZIP 保留原有校验和与上游许可证。
- 发布前核对归档清单，并扫描源码中的个人主目录、个人邮箱、私钥和高置信度令牌模式；归档内容另与本机已知 MCP token、数据库密码做精确比对。
- Git 提交使用 GitHub noreply 邮箱。仓库公开，源码与 Release 附件无需登录即可获取。每次发布都须审查历史与新增内容，不能依赖私有可见性保护使用数据。

`.gitignore` 只影响未跟踪文件；后续添加文件仍应审查暂存清单。使用后的 work、凭据、数据库和工程文件应留在本机，不要把整个已使用目录压缩替换 Release 附件。

下载附件的 SHA-256 与验收范围以对应版本的 Release 和 `docs/releases` 记录为准。自 v2026.10.20.2 起采用公开下载，历史文档中的授权下载要求已废止。项目原创代码与文档采用根目录 MIT 许可，第三方许可及源码材料分别保留。
