# InoProShop MCP 0.1.0 发布验收报告

核对日期：2026-10-12。状态：P0 实现与本机工程能力门槛已通过。最终源码包移位安装结果及 ZIP 哈希另存外部 `source_release_v2_smoke.json`，须与本文共同核对后放行该包。本文不把候选生成、工具受理、语义错误或测试跳过计作任务成功。

## 已交付的实现

独立 CPython MCP 服务及 23 个类型化工具；本机回环 HTTP、访问凭据与控制器单例；IronPython 主线程桥接；工程与宿主绑定；不可变快照、源码回读、原生编译和诊断；SQLite 持久作业、幂等、检查点及审计；已有 ST 实现修改与受控新建 FB 接入；CGC/Neo4j PLC 图、来源和版本隔离；去抖监测、规则、资料包原子发布；OMP 配置、PLC Skill、26 个合成模型任务及安装/恢复文档。

创建采用补偿恢复，先还原调用者，再删除已记录且未经后改的新增 GUID。创建、删除和两对象恢复未经本机原生证据验证时，自动创建保持关闭。源变更、人工后改、未知原生结果和未知对象归属不能靠重复调用绕过。

保存响应丢失支持显式只读对账，校验原宿主实例、目标路径、稳定源码与配置事实及原生 clean 状态，不重放保存；磁盘重开验证仍单独标记。重建索引不重做已完成的工程修改。

## 模型基线的解释

26 个合成任务初次回答中，20 个符合输出契约，6 个经第 1 轮契约反馈后产生合格候选。这是输出结构指标。该批次是禁用工具的离线候选生成会话，输入为合成源码及任务要求；拟议工具名、来源引用和逻辑意图另行审阅，不是 26 次自主工具工作流。26 题原始逐轮证据保留在 `artifacts/mcp_p0/model_evaluation_v1_20261012`，不覆盖初次失败。

Codex 独立源码审阅见 `model_semantic_review_20261012/review.json` 和 `review.md`：17 个非修改回答为 6 符合、9 失败、2 证据不足；9 个修改候选为 6 符合意图、3 偏离。E10 改变固定阈值语义，E11 加入未要求的自锁/许可逻辑，E13 未实现要求的输出赋值。该审阅不代替用户业务验收，也不等于原生编译结果。

编译率、两轮内任务完成率、耗时与人工修改量按实际参加编译的题目单独计数。编译通过不能消除语义失败；新增候选必须重新审阅。本版建立基线，没有采用未经证明的 80%/95% 放行门槛。

本轮 9 个修改/创建候选均在首次原生编译尝试通过，且恢复成功；结合独立意图审阅，任务完成为 6/9。没有发生新的编译反馈修复轮次，不能据此声称原生编译修复效果已全面验证。26 题的契约修复记录与这 9 题的编译分母分别保留。

固定指标见 `model_evaluation_metrics_20261012_final.json`。32 个生成轮次累计进程墙钟时间 343.034 秒（含并行任务累计，非整批耗时）；9 个候选原生编译累计 10.202 秒，基线编译累计 9.297 秒；含索引、应用、恢复、独立工具会话与夹具清理的原生阶段为 487.278 秒。9 个实际编译候选均与模型输出逐字节一致，人工候选编辑为 0；3 个语义失败任务尚需的业务修正量保持 null，没有伪报为 0。

另一次真实 OMP 模型会话已主动调用 `ino_read_object → ino_preview_change → ino_apply_change → ino_get_operation → ino_get_diagnostics`，原生编译通过，随后验收驱动恢复检查点。该会话只开放 5 个限定工具，工具结果只投递经原生回读核对的合成源码；未开放环境、文件、通用脚本或其他工程访问。最终模型回答正确区分内存修改与磁盘保存。

同一去抖修复版本有 3 次独立测量，最后一次写入回包至变化事件发布分别为 14.4341、12.8550、14.0144 秒：最小 12.8550 秒、中位 14.0144 秒、最大 14.4341 秒，去抖配置均为 10 秒。每次只发布第三次最终编辑，额外观察 11 秒均无重复；这是本机小样本，不能外推成大工程 SLA。

## 实际能力边界

- 原生编译验证活动 Application 及确定的任务调用范围；未引用对象、动态调用、库内部和 PLC 运行行为不在该证明内。
- 编辑器尚未提交至对象模型的缓冲区同步状态仍为 unknown；宿主事件泵正常不等于验证所有编辑器缓冲行为。
- Unicode 源码可传输与回读，但本机 AM600 编译器拒绝了测试中的中文新 FB 标识符；ASCII 创建单独通过验证。
- 启动初始化需要正常 UI 消息处理。当前 45/30 秒编译排队等待属于已观察的保守余量，不是厂商就绪 API；实际编译仍必须有完成证据。
- 静态关系与规则公开列出未解析部分。规则是词法建议，不是编译器或设备安全证明。
- LD/SFC 图形修改、通用声明/接口修改、跨对象重命名、任务配置修改、原生插件、PLC 在线操作不在首期范围。
