# 固定脱敏评估集 v1

本目录含 26 个完全合成任务，包括 2 个明确声明、实例、完整参数映射、调用位置和调用条件的新 FB 创建题；代码、变量、对象标识、数值和设备情景均为教学构造，未复制客户工程、安装示例、设备地址或凭据。`sources.json` 是共享输入，`tasks.json` 给出每题输入、请求与验收断言；有 `overrides` 的题先按对象 ID 覆盖输入。合成任务定义不等于已经通过原生编译或 PLC 运行。

先运行 `scripts/evaluate.py` 检查任务和输出评估清单；不调用模型。真实运行仅使用此目录输入，经 OMP 调用已连接的 InoProShop 副本，逐题记录独立 operation_id、patch_hash、编译原文、工具调用数、耗时和人工修改量。对需要源码变更的任务，宿主必须先导入对应合成输入并建立任务调用；未完成部署时记录 `blocked_fixture_not_loaded`，不能用语言模型自述代替原生验证。

每题最多两轮候选修复，不无限重试。`evaluation-template.json` 为结果格式。指标分母只取实际运行且具备相应编译验收条件的题，未运行、受阻及纯解释题分开计数。第一次编译通过率、两轮内任务完成率、正确拒绝率不得合并；不把静态/编译结果称为设备正确率。

`run-model-evaluation.py` 是实际 OMP 模型运行器，模型无工具、MCP 或文件访问能力。修复只能带真实契约拒绝或原生编译拒绝证据，参数硬限 round 1/2，不能覆盖已有响应。完整回复仅在本地保存；进入后续原生写入前必须先通过候选契约校验。模型产生代码不等于代码已经被应用。

真值答案仅约束题目给定情景。所有控制逻辑均为普通 PLC 离线示例，未验证真实设备运行、扫描时序或功能安全。
