# PLC 智能工程助手

**适用于 InoProShop · 面向企业客户与工程负责人的开源智能工程助手**

帮助工程团队理解已有程序、定位相关信息、复核修改方案，并在工程副本中检查编译与恢复结果。沿用现有 InoProShop 工程环境，通过配套对话入口提出任务，由工程师把握修改范围和交付判断。

## 从哪些任务开始

| 评估任务 | 希望得到的结果 |
|---|---|
| 接手已有工程 | 了解一个程序的逻辑、变量和调用关系，并知道说明依据来自哪里。 |
| 排查或评审变更 | 定位相关代码与使用位置，区分已读取内容和仍需人工核查的部分。 |
| 验证一处修改 | 先查看差异，在确认的范围内修改工程副本，再检查编译结果与恢复方式。 |

## 核心能力

- **工程理解**：结合可读取的工程内容解释程序，保留信息来源和覆盖范围。
- **检索定位**：查找文本、变量及相关用法，为排查与复核提供依据。
- **受控修改**：支持结构化文本（ST）程序的声明与逻辑调整，以及已准备模板的工程副本创建；修改范围与条件明确。
- **验证交付**：呈现变更、编译、保存和恢复结果，帮助工程师决定下一步。

产品能力按“工程理解 → 检索定位 → 受控修改 → 验证交付”协同，变更复核、过程留痕和异常恢复贯穿其中。[查看产品能力架构](docs/PRODUCT_OVERVIEW.md)。

## 如何开始使用

1. **确认评估条件**：自行选择要验证的工程与任务，核对适配环境；源码和完整离线包均可公开获取。
2. **连接工程环境**：获取完整离线包，完成准备，在接入的 InoProShop 中选择工程副本。
3. **先做只读体验**：理解一个程序，再定位一个变量，检查结果是否有来源、范围是否清楚。
4. **再验证受控修改**：本机修改与编译能力确认后，在副本上预览一处变更，核查编译、保存及恢复结果。
5. **形成评估结论**：记录已完成任务、适用条件与剩余问题，作为是否继续部署的依据。

环境连接、只读体验和受控修改分阶段确认。连接完成后可先体验读取；修改、编译与模板创建还需满足本机验证和模板准备条件。[阅读客户使用与评估手册](services/inoproshop-mcp/docs/OFFLINE_README.md)。

## 使用条件与适用范围

当前已验证的组合为 **Windows x64、InoProShop 1.10.0.3、ohmypi 18.8.7**。使用方需准备相应软件授权、可用的模型配置及可评估的工程副本。其他环境与设备型号需单独确认。

本版评估重点为可读取的 ST 文本内容及已验证的工程操作。模板由部署负责人准备，部分加密、图形或未读取内容需要人工检查。工程师仍须完成工艺复核、设备联调与现场运行确认。

完整离线包已包含本产品所需的运行依赖，依赖准备无需联网；云模型交互仍需相应网络，发送信息的处理取决于所选服务。[了解数据与使用边界](docs/PRIVACY.md)。
